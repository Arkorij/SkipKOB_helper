# SkipKOB_Helper

Приложение для учёта прогулов в университете. Тёмная тема, простой интерфейс.
Кроссплатформенно (Android — основная цель, плюс Windows) на **Flet** (Python).

## Возможности

- **Статистика** — счётчики прогулов (всего, уваж./неуваж., полных пропущенных дней),
  круговая диаграмма по причинам, прогулы по предметам, посещаемость консультаций.
- **Расписание по неделям** (1–40), чётные/нечётные недели, отметка статуса для каждой пары:
  пришёл / справка / уваж. причина / проспал / не захотел / всё сдал / пара отменена.
  У каждой пары цветной значок типа: **Лекция** или **Практика** (лабораторная = практика).
  Переключение недель: кнопками или свайпом (перетянуть список за верх/низ).
  Изменение пар конкретного дня (override).
- **Консультации** — приглушённые пары, отмечаются «пришёл / не пришёл», в прогулы
  не идут, но учитываются в статистике посещений.

### Синтаксис строки пары (в редакторе и при ручной правке дня)

Одна пара = одна строка. Префиксы в начале строки:

- `#` — консультация
- `*` — практика/лабораторная (без `*` — лекция)

Примеры: `Математика` (лекция), `* Базы данных` (практика), `# Языки программирования`
(консультация), `#* Физика` (консультация-практика).

### Импорт расписания (.conf / .json)

Настройки → «Импорт расписания» принимает файл `.conf` или `.json`. Файл содержит
`academic_year_start`, `breaks` и `base_schedule` и **перезаписывает базовое расписание**
(отметки прогулов при этом сохраняются). Пары хранятся как
`{"name", "kind": "lecture"|"practice", "consultation": true|false}`.
- **Настройки** — учебный год (определяет календарь), каникулы (на них нумерация недель
  останавливается), редактор базового расписания (нечётная/чётная неделя), экспорт/импорт
  расписания (JSON), экспорт отчёта (Markdown), полный сброс с таймером.

## Запуск (разработка)

```bash
pip install -r requirements.txt
python main.py            # откроется окно (desktop)
# либо в браузере:
flet run --web main.py
```

> Требуется Python 3.9+ (проверено на 3.14). Flet тянет встроенный клиент Flutter
> при первом запуске.

## Сборка

```bash
# Android (.apk) — нужен установленный Flutter SDK; flet build поставит его при необходимости
flet build apk

# Windows
flet build windows
```

## Логика «полного прогуленного дня»

Учитываются только «зачётные» пары (не консультации, не «отменена», не «всё сдал»).
Если зачётных пар нет — день не пропущен. Если хоть на одной «пришёл» — день не полный.
Если все зачётные пары пропущены (по любой причине) — день полностью пропущен.

## Хранение данных

Локально, файл `data.json`:
- Windows: `%APPDATA%/SkipKOB_Helper/data.json`
- На упакованном приложении (Android/desktop): каталог `FLET_APP_STORAGE_DATA`.

Перенос между устройствами — через экспорт/импорт расписания и ручное копирование.

```
  ui/

    widgets.py          # переиспользуемые виджеты
    stats_page.py       # страница «Статистика»
    schedule_page.py    # страница «Расписание»
    settings_page.py    # страница «Настройки»
```
