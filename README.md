## Возможности

### Статистика
- Счётчики: всего прогулов, полных пропущенных дней, уважительные и неуважительные
- Кольцевая диаграмма причин — похожие причины различаются оттенками
- Прогулы по предметам в двух режимах: **суммарно** и **детально** (отдельно лекции,
  практики и лабораторные по каждому предмету)
- Отдельный блок «не считается прогулом»: освобождён от пары, отменённые пары,
  посещённые консультации

### Расписание
- Учебные недели **1–40**, чётные и нечётные с разным базовым расписанием
- У каждой пары цветной значок типа: `Лекция` `Практика` `Лабораторная` `Консультация`
- Статусы: пришёл · справка · уваж. причина · проспал · не захотел · нет сил ·
  всё сдал · пара отменена
- Смена недели: кнопками, выбором из сетки или **протягиванием списка за край**
- Изменение расписания на конкретный день, не ломая базовое
- Последняя открытая неделя запоминается

### Настройки
- Учебный год — по 1 сентября строится весь календарь
- **Каникулы**: на них нумерация недель останавливается
- Редактор базового расписания на чётную и нечётную неделю
- Экспорт и импорт расписания (`.conf` / `.json`)
- Экспорт отчёта о прогулах в Markdown — удобно читать и скормить ИИ для анализа
- Свайп между страницами — отключаемый
- Полный сброс с предупреждением и таймером

## Как считается «полный пропущенный день»

Учитываются только «зачётные» пары — без консультаций, отменённых пар и «всё сдал».

| Ситуация | Результат |
|---|---|
| Все пары отменены или всё сдано | день **не** пропущен |
| Хоть на одной паре «пришёл» | день **не** пропущен |
| Все зачётные пары пропущены (любая причина) | день пропущен **полностью** |
| Половина отменена, половина прогуляна | день пропущен **полностью** |

## Формат расписания

Пары задаются по одной в строке. Префиксы в начале строки:

| Префикс | Значение |
|---|---|
| *(нет)* | лекция |
| `*` | практика |
| `~` | лабораторная |
| `#` | консультация |

Префиксы комбинируются: `#~ Физика` — консультация по лабораторной.

Пример готового файла — [`schedule_SO211KOB.conf`](SkipKOB_Helper/schedule_SO211KOB.conf).

## Установка

**Android** — скачать APK из [релизов](https://github.com/Arkorij/SkipKOB_helper/releases/latest),
открыть на телефоне и разрешить установку из неизвестных источников.

**Windows** — скачать архив, распаковать целиком и запустить `skipkob_helper.exe`.
Папку держать целиком: рядом с exe лежат необходимые библиотеки.

## Сборка из исходников

```bash
cd SkipKOB_Helper
flutter pub get
flutter run
```

Полные инструкции и структура кода — в [README приложения](SkipKOB_Helper/README.md).
Журнал разработки, решения и грабли — в [DEVELOPMENT.md](DEVELOPMENT.md).

## Хранение данных

Всё локально, никаких серверов и аккаунтов:

- **Windows:** `%APPDATA%\com.arkorij\skipkob_helper\data.json`
- **Android:** внутренний каталог приложения

Перенос между устройствами — через экспорт и импорт файла расписания.
