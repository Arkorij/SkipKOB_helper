Полное переписывание [Classic-версии](../SkipKOB_Helper_Classic/) на Dart. Возможности
те же, отличается тем, что можно управлять всем поведением интерфейса напрямую.

**Зачем понадобилось.** В версии на Flet свайп между страницами доводился медленной
пружиной Flutter, и Flet не даёт до неё добраться: страница выглядит долистанной, но
ещё едет, и следующее касание перехватывается ею вместо прокрутки. На Dart это одна
строка настройки — см. [ниже](#пружина-доводки-свайпа).

## Что изменилось по сравнению с Classic

| | Classic | Test |
|---|---|---|
| Размер APK | ~75 МБ | **~21 МБ** — уходит Python-рантайм |
| Физика жестов | недоступна | полностью настраивается |
| Протягивание за край | по косвенным признакам | нативно, `dragDetails` |
| Индикатор протягивания | через Python, с задержкой | локально, мгновенно |
| Диаграмма | встроенная в Flet | своя, на `CustomPainter` |

Функционально версии совпадают: те же статусы, то же правило «полного дня», тот же
формат данных.

## Пружина доводки свайпа

То, ради чего всё затевалось:

```dart
// lib/main.dart
final snappySpring = SpringDescription.withDampingRatio(
  mass: 0.5,       // у Flutter по умолчанию 80 — намеренно тяжёлая
  stiffness: 450,  // по умолчанию 100
  ratio: 1.1,      // чуть передемпфировано, чтобы не было отскока
);

class SnappyPageScrollPhysics extends PageScrollPhysics {
  @override
  SpringDescription get spring => snappySpring;
}
```

Палец ведёт страницу, отпустил — доводка **добивается резко**, а не доползает.
Три числа выше — единственные ручки, которыми настраивается ощущение.

Свайп по умолчанию **выключен**, включается в настройках: `Настройки → Интерфейс`.
При выключенном свайпе страницы листаются только нижней панелью
(`NeverScrollableScrollPhysics`), переход по кнопке — 130 мс.

## Структура

```
lib/
├── main.dart                    точка входа, оболочка, физика свайпа
├── app_state.dart               общее состояние и уведомление страниц
├── core/                        ядро без интерфейса
│   ├── models.dart              статусы, типы занятий, разбор строки пары
│   ├── calendar.dart            недели ↔ даты, чётность, каникулы
│   ├── resolver.dart            пары конкретного дня и отметки
│   ├── stats.dart               статистика, правило «полного дня», отчёт
│   └── store.dart               модель данных и JSON-хранилище
└── ui/
    ├── theme.dart               палитра, размеры, общие виджеты
    └── pages/
        ├── stats_page.dart      статистика с кольцевой диаграммой
        ├── schedule_page.dart   расписание, протягивание за край
        └── settings_page.dart   настройки, импорт/экспорт, сброс
```

### Особенности сборки

Шаблон Flutter пришлось поправить в двух местах, иначе APK не собирается:

- **Kotlin** поднят с 1.8.22 до 2.1.0 в `android/settings.gradle.kts` — шаблонная
  версия слишком старая для современных плагинов
- **Версия NDK** зафиксирована как `27.0.12077973` в `android/app/build.gradle.kts` —
  её требуют плагины

## Установка рядом с Classic

Обе версии ставятся одновременно и не мешают друг другу:

| | Classic | Test |
|---|---|---|
| Пакет | `com.arkorij.skipkob_helper` | `com.arkorij.skipkob_helper_test` |
| Название | SkipKOB Helper | **SkipKOB Test** |
| Данные | своё хранилище | своё хранилище |

Данные у них раздельные, но **формат файлов одинаковый** — выгрузи расписание из
Classic (`Настройки → Экспорт расписания`) и импортируй в Test.
